❌⭕ PRODIGY_WD_03 – Tic-Tac-Toe Web Application
An interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript as part of the Prodigy InfoTech Web Development Internship – Task 03.

✨ Features

🎮 Two-player Tic-Tac-Toe game (X and O)
🏆 Automatic win detection for rows, columns, and diagonals
🤝 Draw detection when all cells are filled
🔄 Restart button to reset the game
📱 Fully responsive across desktop and mobile devices
⚡ Clean and intuitive game interface

🎮 How to Play

The game is played on a 3x3 grid
Player X always goes first
Players take turns placing their mark (X or O)
First player to get 3 in a row wins
If all 9 squares are filled with no winner it's a draw
Click Restart to play again
